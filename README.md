# Blackboard Studio Alpha

An earlier public release of **Blackboard Studio**, a node-based creative workspace for visual effects and compositing.

**[Try the Alpha](https://promto-c.github.io/blackboard-studio-alpha/)** · **[Latest hosted edition](https://xn--b1a.studio/)**

## About this release

This repository preserves an older alpha edition. The latest hosted edition is developed separately and may have different features and behavior. Releases from this repository do not automatically track the latest edition.

## Run locally

Requires Node.js and pnpm.

```bash
pnpm install
pnpm dev:studio
```
